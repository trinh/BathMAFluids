Example 4.1.2 Uniform flow.

Find the velocity potential \(\phi\) and the velocity \(\bu\) of a uniform flow of speed \(U\) directed at angle \(\alpha\) to the \(x\)-axis.
🔗
Solution.
The velocity is constant, \(\bu = U[\cos\alpha, \sin\alpha]\text{.}\) Integrating \(\pd{\phi}{x} = U\cos\alpha\) and \(\pd{\phi}{y} = U\sin\alpha\) gives, up to a constant, the linear function
\begin{equation*} \phi(x, y) = Ux \cos\alpha + Uy \sin\alpha, \end{equation*}
which clearly satisfies \(\nabla^2\phi = 0\text{.}\) The streamlines are shown below.
