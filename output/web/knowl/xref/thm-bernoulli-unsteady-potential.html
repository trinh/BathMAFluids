Theorem 3.5.9 Bernoulli’s equation for unsteady potential flow.

For an irrotational, possibly unsteady, flow with velocity potential \(\phi\text{,}\) so that \(\bu = \nabla\phi\text{,}\)
\begin{equation} \pd{\phi}{t} + \frac{1}{2}|\nabla\phi|^2 + \frac{p}{\rho} + \chi = F(t),\tag{3.5.9} \end{equation}
for some function \(F(t)\text{.}\)
🔗
🔗

Proof.
Set \(\bomega = \mathbf{0}\) and \(\bu = \nabla\phi\) in (3.5.5). Since space and time derivatives commute, \(\pd{}{t}(\nabla \phi) = \nabla\left(\pd{\phi}{t}\right)\text{,}\) and so
\begin{equation*} \nabla\left( \pd{\phi}{t} + \frac{1}{2}|\nabla\phi|^2 + \frac{p}{\rho} + \chi \right) = \mathbf{0}. \end{equation*}
The quantity in brackets therefore has no spatial dependence, i.e. it is a function of \(t\) alone.
